## B. 本番制作の見積もり（**推定値・要確認**）

各ツールの料金やクレジットの消費量は頻繁に変わるため、**制作を始める日に、各ツールの公式料金ページで確認してから**確定してください。下の数字は計画を立てるための目安です。

### 生成する量

| 項目 | 数量 |
|---|---|
| 生成が必要な映像ショット | 23（S24・S25 はテキストカードなので生成不要） |
| 1ショットあたりの試行回数 | 平均 4 回（簡単なもの 2〜3 回、S10・S12・S20・S21 は 6〜10 回） |
| 生成するクリップ数 | 約 90〜100 本（各 5 秒、1080p） |
| キーフレーム画像（画像から動画を作る場合） | 23 ショット × 4〜8 枚 ＝ 約 100〜180 枚 |
| キャラクター参照画像 | 3 匹 × 7 カット（候補を含めて約 150 枚を生成） |

### 費用の計算式

```
映像生成費 ＝ クリップ数 × 5秒クリップ1本の単価
画像生成費 ＝ 画像枚数 × 1枚の単価（定額プランなら月額）
音素材費   ＝ 効果音・BGM ライブラリの月額（または素材ごとの購入費）
```

| 項目 | 推定の幅 |
|---|---|
| 映像生成（約 100 本） | 約 5,000〜25,000 円（ツールとプランによる） |
| 画像生成 | 約 0〜5,000 円（定額プランの範囲内で収まることが多い） |
| 音素材（ライブラリ 1 か月分） | 約 0〜3,000 円 |
| **合計** | **約 5,000〜33,000 円** |

### 作業時間（推定）

| 工程 | 時間 |
|---|---|
| 参照画像の作成と選定 | 3〜5 時間 |
| キーフレームと映像の生成、選定 | 8〜14 時間 |
| 効果音・鳴き声の収集と録音 | 2〜3 時間 |
| 組み立て、修正、確認 | 2〜3 時間 |
| **合計** | **15〜25 時間** |

### ライセンスの確認ポイント
- AI 生成ツール：**商用利用（YouTube の収益化）が今のプランで許されているか**、生成物の権利が誰に帰属するか、クレジット表記が必要か。
- フリー素材サイトの音：ファイルごとにライセンスが違う。CC0 か、商用利用できるライセンスのものだけを使い、ページの URL を記録する。
- YouTube の「改変または合成されたコンテンツ」の開示：アップロード時に、AI で生成したリアルな映像であることを申告する（この動画は申告の対象になる）。
